# AR Notes User Manual

## Getting Started
1. Run the enhanced gesture system
2. Position your hand in front of the camera
3. Use finger counting to select categories:
   - 1 finger: Documents
   - 2 fingers: Images
   - 3 fingers: Videos
   - 4 fingers: Audio
   - 5 fingers: Code

## File Selection
1. After selecting a category, files will be numbered
2. Show fingers corresponding to file number
3. Give thumbs up to confirm and open

## Tips for Best Results
- Ensure good lighting
- Keep hand steady for 1-2 seconds
- Use clear finger positions
- Wait for confirmation sound before next gesture
